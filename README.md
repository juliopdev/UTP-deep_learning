# Clasificador con Deep Learning en GitHub Pages

Proyecto de clasificación en tiempo real usando **Google Teachable Machine** y **TensorFlow.js**, publicado mediante **GitHub Pages**.

## 🌐 Demo en Vivo
Puedes probar la aplicación en el siguiente enlace:
👉 **[Ver Demo en GitHub Pages](https://juliopdev.github.io/UTP-deep_learning/)**

---

## 🛠️ Tecnologías Utilizadas
- **[Google Teachable Machine](https://teachablemachine.withgoogle.com/):** Entrenamiento y exportación de la red neuronal mediante Transfer Learning.
- **[TensorFlow.js](https://www.tensorflow.org/js):** Inferencia del modelo directamente en el navegador del cliente.
- **HTML5 & CSS3:** Interfaz responsiva y amigable con indicadores de probabilidad en tiempo real.
- **GitHub Pages:** Alojamiento y despliegue continuo y gratuito de la aplicación estática.

---

## 🚀 Cómo Usar
1. Ingresa al enlace de la demo.
2. La URL del modelo ya viene cargada por defecto (`https://teachablemachine.withgoogle.com/models/li6odylsX/`).
3. Haz clic en el botón **"Iniciar"**.
4. Concede los permisos a la cámara web cuando el navegador lo solicite.
5. Observa cómo la red neuronal clasifica lo que ve la cámara con sus respectivos porcentajes de confianza en tiempo real.
